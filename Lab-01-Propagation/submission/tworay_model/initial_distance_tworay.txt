Initial Distance Calculation - Two-Ray Ground Propagation Model
=================================================================
 
Source: Lab1_Cpp_TwoRay.cc (ns-3.40, 802.11a IBSS @ 6 Mbps, 5.18 GHz)
 
Parameters used (from code):
-----------------------------
Pt (TxPowerStart/End)   = 23 dBm
Gt, Gr (antenna gain)   = 0 dB (not set -> default, linear = 1)
Ht = Hr (antHeight)     = 1.5 m
f (Frequency)           = 5.18 GHz
RxSensitivity           = -92 dBm
SystemLoss (L)          = 1 (default, not set)
MinDistance             = 1.0 m (not relevant here since di >> 1 m)
 
Step 1: Wavelength
-------------------
lambda = c / f = 299792458 / 5.18e9 ≈ 0.057875 m
 
Step 2: Crossover distance (Friis -> Two-Ray switch point in ns-3)
--------------------------------------------------------------------
dCross = (4 * pi * Ht * Hr) / lambda
       = (4 * pi * 1.5 * 1.5) / 0.057875
       ≈ 488.5 m
 
Step 3: Convert power values from dBm to Watts
-------------------------------------------------
Formula: P(W) = 10^(P(dBm)/10) / 1000
 
Pt = 10^(23/10) / 1000  ≈ 0.19953 W
Pr (threshold, = RxSensitivity) = 10^(-92/10) / 1000 ≈ 6.3096e-13 W
 
Step 4: Solve Two-Ray Ground equation for distance
-----------------------------------------------------
Two-Ray Ground formula:
    Pr = (Pt * Gt * Gr * Ht^2 * Hr^2) / (d^4 * L)
 
Solve for d:
    d^4 = (Pt * Gt * Gr * Ht^2 * Hr^2) / (Pr * L)
    d   = [ (Pt * Gt * Gr * Ht^2 * Hr^2) / (Pr * L) ]^(1/4)
 
Numerator = Pt * Gt * Gr * Ht^2 * Hr^2
          = 0.19953 * 1 * 1 * (1.5^2) * (1.5^2)
          = 0.19953 * 5.0625
          ≈ 1.0101
 
d^4 = 1.0101 / 6.3096e-13 ≈ 1.6009e12
 
d_i = (1.6009e12)^(1/4) ≈ 1124.841314 m
 
Sanity check: d_i (1124.8 m) > dCross (488.5 m), confirming the point where
Pr drops to the sensitivity threshold falls in the Two-Ray regime (d > dCross),
so using the Two-Ray formula (rather than Friis) to solve for d_i was correct.
