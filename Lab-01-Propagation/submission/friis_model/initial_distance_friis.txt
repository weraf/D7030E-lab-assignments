Initial Distance Calculation - Friis Propagation Model
=========================================================

Parameters (from code):
Pt (TxPowerStart/End)   = 23 dBm
Gt, Gr (antenna gain)   = 0 dB (not set -> default, linear = 1)
f (Frequency)           = 5.18 GHz
RxSensitivity           = -92 dBm
SystemLoss (L)          = 1 (default)
MinDistance             = 0.5 m (default, not relevant here since di >> 0.5 m)
 
Step 1: Wavelength
-------------------
lambda = c / f = 299792458 / 5.18e9 ≈ 0.057875 m
 
Step 2: Convert power values from dBm to Watts
-------------------------------------------------
Formula: P(W) = 10^(P(dBm)/10) / 1000
 
Pt = 10^(23/10) / 1000  ≈ 0.19953 W
Pr (threshold, = RxSensitivity) = 10^(-92/10) / 1000 ≈ 6.3096e-13 W
 
Step 3: Friis received-power equation (ns-3 implementation)
---------------------------------------------------------------
    Pr = (Pt * Gt * Gr * lambda^2) / ((4*pi)^2 * d^2 * L)
 
Solve for d:
    d_i = lambda * sqrt( (Pt * Gt * Gr) / ((4*pi)^2 * Pr * L) )
 
Step 4: Substitute values
-----------------------------
(4*pi)^2 = 16*pi^2 ≈ 157.9137
 
Pt / (16*pi^2 * Pr * L) = 0.19953 / (157.9137 * 6.3096e-13) ≈ 2.00254e9
 
sqrt(2.00254e9) ≈ 44749.7
 
d_i = 0.057875 * 44749.7 ≈ 2589.89 m

d_i = 2589.89 m
 
Distance set D = { d_i, 7d_i/8, 6d_i/8, 5d_i/8, 4d_i/8, 3d_i/8, 2d_i/8, d_i/8 }
(step size = d_i/8 ≈ 323.736 m)
D = {2589.9 2266.2 1942.4 1618.7 1294.9 971.2 647.5 323.7}
 
--------------------------------------------------
To run the distances:

distances=(2589.9 2266.2 1942.4 1618.7 1294.9 971.2 647.5 323.7)
for d in "${distances[@]}"; do
  scripts/run_cpp.sh Lab-01-Propagation/code/Lab1_Cpp_Friis.cc --distance=$d | grep "^CSV" | tee -a friis_csv_only.txt
done
